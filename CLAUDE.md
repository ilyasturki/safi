# About Safi

Safi is a minimalist text-editing web application. The interface provides a distraction-free, monospace editing surface. It is designed primarily as a self-hosted application, giving users full control over their data and environment. Think of it like a web based version of obsidian but more in the minimalist and vim style of thinking.

# Inspirations

- [AI Writer](https://ia.net/writer)
- [Notepads](https://www.notepadsapp.com/)
- [Obsidian](https://obsidian.md/)

# Tech Stack

- **Meta-Framework**: Nuxt 4
- **Framework**: Vue 3 with Composition API and TypeScript
- **Styling**: TailwindCSS v4
- **Editor**: CodeMirror 6
- **Icons**: Lucide icons
- **Containerization**: Docker (for self-hosted deployment)
